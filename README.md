# English Learning Desk

English | [中文](README.zh-CN.md)

An offline flashcard app for living and studying in the UK, with spaced repetition and
AI-generated example sentences and quizzes. Open `学习台.html` in a browser; no server, account or
network connection is needed. The UI and code comments are in Chinese.

## Features

- **Word bank:** 2,366 distinct words and phrases in 27 themed decks (`deck-parts/`), covering
  topics such as housing and bills, the NHS, academic writing and AI/ML vocabulary.
- **Spaced repetition:** scheduling with the FSRS algorithm (`fsrs.js`). Progress is kept in the
  browser's local storage, with export and import for backups.
- **Pronunciation:** offline audio generated by `生成发音.py` (edge-tts), with the browser's speech
  synthesis as a fallback.
- **AI examples and quizzes** (`gen_examples.py`, `ai_card.py`): for every word, Claude
  (`claude-haiku-5-5`, structured output) writes three example sentences with Chinese
  translations and one four-option cloze question. Generation runs offline and the results are
  saved to `ai-examples.json` / `ai-examples.js`, so the API key never reaches the web page.

## Validation of AI output

Every generated card is checked in code, and cards that fail are regenerated (up to 3 attempts):

- each example sentence uses the target word; the question has exactly one blank and four
  distinct options;
- no word is repeated around the blank, and the correct option is related to the target word;
- the model also returns the completed sentence; the code fills the blank itself and compares the
  two word by word.

**Spot check:** a random sample of 20 words (`抽查.csv`, graded by Claude rather than by a person)
found 1/60 example sentences with the wrong word sense, 0/60 translation errors, and 7/20 quiz
questions with a defect, mostly a distractor that also fits the blank. Generating all 2,366 words
cost about $1.29 in API fees.

## Generation details

- `--limit` caps how many new words one run generates. Words that already have examples are
  skipped, so re-running the same command resumes an interrupted run.
- `--workers` sets how many words are processed in parallel. The account's output limit is 80,000
  tokens per minute and each word uses about 900 output tokens, so 8 workers stay within it.
- `--words FILE` generates only the listed words; `--out PREFIX` writes to separate files and
  leaves `ai-examples.json` untouched.
- After generation the position of the correct option is shuffled, and rejection reasons are
  logged to `gen_rejects.log`.

Runs on 2026-10-25 (cost estimates printed by `gen_examples.py`, at $0.10 / $0.50 per million
input / output tokens):

| Run | Words | Input tokens | Output tokens | Cost (USD) |
|---|---|---|---|---|
| Pilot batch | 22 | 22,813 | 20,019 | 0.0123 |
| Full run 1 | stopped early, 96 saved (`PermissionError`: output file locked) | – | – | not printed |
| Full run 2 (8 workers, 25.5 min) | 2,270 | 2,467,924 | 2,025,502 | 1.26 |
| Re-run after relaxing checks | 23 | 23,922 | 27,807 | 0.0163 |

The 23 re-run words were mostly false rejections from over-strict checks (for example, an example
for `pull your weight` written as `pull his weight`). One more (`Do you mind if I put the heating
on?`) had "turn" as its answer and did not test the phrase itself; the relaxed checks caught it.
All 23 were regenerated with none skipped.

## Limitations

- Of the 7 flawed quiz questions in the spot check, 1 reads wrongly once filled in
  (`return to sender`) and 6 have another option that also fits (for example, "3-____" for `nil`
  also works with "one"). The stems give too little context; code cannot detect this, so it needs
  a better prompt or a second model pass at extra cost.
- Wrong tense or wrong word sense cannot be detected in code either and is found only by spot
  checks; one example for `Push / Pull` used "push in" (to jump a queue).

## Quick start

```powershell
# open the app
.\打开学习台-用Edge.bat          # or open 学习台.html in any browser

# regenerate AI examples (needs ANTHROPIC_API_KEY in the environment)
python -m pip install "anthropic>=1.17,<2"
python gen_examples.py --deck all --limit 5000 --workers 8

# regenerate audio
& '.\生成发音.ps1' --limit 20

# tests (Node.js)
node _test_fsrs.js
node _test_persist.js
node _test_recap.js
node _test-bridge.js
node _test_voice.js 学习台.html
```
