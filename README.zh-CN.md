# 英语学习台（English Learning Desk）

[English](README.md) | 中文

一个离线运行的背词应用，面向在英国生活和学习的场景，结合间隔重复和 AI 生成的例句与小测验。用浏览器直接打开 `学习台.html` 即可使用，不需要服务器、账号或网络。界面和代码注释均为中文。

## 功能

- **词库：**2,366 个不同的单词和短语，分为 27 个主题词组（`deck-parts/`），涵盖租房和账单、NHS 就医、学术写作、AI/机器学习词汇等主题。
- **间隔重复：**用 FSRS 算法安排复习（`fsrs.js`）。学习进度保存在浏览器的本地存储中，支持导出和导入备份。
- **发音：**`生成发音.py`（edge-tts）生成的离线音频；没有音频时退回浏览器自带的语音合成。
- **AI 例句和小测验**（`gen_examples.py`、`ai_card.py`）：Claude（`claude-haiku-5-5`，结构化输出）为每个词生成 3 个带中文翻译的例句和 1 道四选一填空题。生成过程离线运行，结果保存为 `ai-examples.json` / `ai-examples.js`，因此 API Key 不会进入网页。

## AI 输出的校验

每张生成的卡片都由代码校验，不合格的卡片会重新生成（最多 3 次）：

- 每条例句都用到目标词；题目恰好有一个空格和 4 个不同的选项；
- 空格前后没有重复的词，正确选项与目标词相关；
- 模型同时返回填好空格的完整句子，代码自行把正确选项填入空格，再逐词比对。

**抽查：**随机抽取 20 个词（`抽查.csv`，由 Claude 判分，而非人工），例句词义错误 1/60，翻译错误 0/60，选择题有问题 7/20，主要是某个干扰项填入后同样成立。2,366 个词全部生成一遍，API 费用约 $1.29。

## 生成细节

- `--limit` 限定单次运行最多新生成多少个词。已有例句的词会被跳过，因此中断后重新运行同一条命令即可继续。
- `--workers` 设定同时处理的词数。账号的输出限额是每分钟 80,000 token，每个词约用 900 个输出 token，8 个并发不会超限。
- `--words 文件` 只生成文件中列出的词；`--out 前缀` 把结果写入另外的文件，不改动 `ai-examples.json`。
- 生成后会打乱正确选项的位置，被打回的原因记录在 `gen_rejects.log`。

## 局限

- 抽查中有问题的 7 道选择题里，1 道填入后句子不通（`return to sender`），6 道还有别的选项同样成立（例如 `nil` 的 "3-____" 填 one 也对）。原因是题干上下文不足；代码无法发现这类问题，只能改进提示词，或者让模型再判一遍（需要额外费用）。
- 时态用错、词义用错同样无法由代码发现，只能靠抽查；例如 `Push / Pull` 有一句例句用的是 push in（插队）。

## 快速开始

```powershell
# 打开学习台
.\打开学习台-用Edge.bat          # 或者用任意浏览器打开 学习台.html

# 重新生成 AI 例句（环境变量里要有 ANTHROPIC_API_KEY）
python -m pip install "anthropic>=1.17,<2"
python gen_examples.py --deck all --limit 5000 --workers 8

# 重新生成音频
& '.\生成发音.ps1' --limit 20

# 测试（Node.js）
node _test_fsrs.js
node _test_persist.js
node _test_recap.js
node _test-bridge.js
node _test_voice.js 学习台.html
```
